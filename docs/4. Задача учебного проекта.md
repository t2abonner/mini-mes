# Задача учебного проекта

Для состовления технического задания учебного проекта, за основу были взяты документы с реального проекта:

- [1. Бизнес требования](1.%20Бизнес%20требования.md) - Документ был предоставлен заказчиком для которого аутсорс компания разрабатывала программное обеспечение (MES).
- [2. Техническое задание](2.%20Техническое%20задание.md) - Документ был разработан менеджером проекта в паре с системным аналитиком, на основе документа 1. Бизнес требования.
- [3. Спецификация реализации системы](3.%20Спецификация%20реализации%20системы.md) - Документ был разработан одним из разработчиков команды, который занимает в данном проекте роль тех.-лид., на основе документа 2. Техническое задание.

## Постановка задачи для учебного проекта

На данный момент, мой уровень знаний и навыков выглядит приблизительно так: Я владею знаниями HTML, CSS, JavaScript, умею верстать, пробовал React, Redux, React router, в общих чертах знают TypeScript. В то время как, для успешного прохождения собеседования с целью трудоустройства, необходимо обладать знаниями гораздо более высокого уровня, нежели просто JavaScript, React, Redux.

В связи с этим, мне необходимо разобраться с рядом технологий о которых потенциально будет идти речь в ходе собеседования.

- TypeScript - 5.x

Что бы разобраться с данными технологиями недостаточно просто почитать про них какие-нибудь статьи в интернете или документацию. Для этого необходимо самостоятельно написать какой-нибудь проект, который не обязательно будет полностью охватывать все что описано в документах 2. Техническое задание и 3. Спецификация реализации системы, я понимаю что это гигантский объём работы для одного человека тем более без реального опыта на стадии обучения. Однако полагаю, что я мог бы написать какой-нибудь проект который будет менее масштабным но при этом будет охватывать полный спектр описанных выше технологий без детального углубления в каждую из них.

Иначе говоря, данное приложение (учебный проект), может быть гораздо проще с точки зрения функциональности но при этом будет охватывать все аспекты заявленного технологического стека, так чтобы я на реальном опыте мог понять как все эти технологии работают и взаимодействуют между собой.

## Контекст учебного проекта

Я фронтенд разработчик аутсорс компании, в составе командного проекта который описывается следующим образом:  
Нашу аутсорс компанию в качестве подрядчика наняла компания которая является производственным предприятием (производство деталей корпусной мебели из ЛДСП) для реализации проекта по разработке программного обеспечения представляющего из себя MES систему для автоматизации и цифровизации внутренних процессов производственного предприятия. Задача стояла создать веб-систему, объединяющую интерфейсы для отдела продаж, конструкторского бюро, складского отдела, а тек же терминалов для операторов и мастера смены в производственном цехе.

### Команда и роли (Проектная команда, 8 человек)

- Менеджер проекта (1)
- Системный аналитик (1)
- Тех.-лид. (1)
- Frontend разработчик (2)
- Backend разработчик (2)
- Тестировщик (1)

### Моя роль

Middle Frontend разработчик.  
Я отвечаю за реализацию frontend-части проекта согласно техническому заданию. Глобальные архитектурые решения принимает наш Тех.-лид.. Моя задача заключается в том, чтобы корректно реализовать, протестировать и интегрировать вверенные мне модули в общую систему, соблюдая сроки и стандарты кода компании.
