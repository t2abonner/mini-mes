# MES-MF: Система оперативного управления производственными процессами мебельного предприятия

**MES-MF** (Manufacturing Execution System for Manufacturing Furniture) — это система автоматизации оперативного управления производством на уровне цеха (Уровень 3 по стандарту IEC 62264) для мебельного B2B-предприятия. Система обеспечивает прослеживаемость незавершенного производства (НЗП) в реальном времени, управление внутрискладской логистикой и предоставляет сквозной аналитический мониторинг для всей команды.
